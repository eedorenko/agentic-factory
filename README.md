# Agentic Factory

Copilot-first agentic software factory experiment.

## Goal

Push GitHub Copilot + GitHub Actions as far as possible toward a unified software factory. Find the hard boundaries where frameworks (L3AgenticSystem, ECorp) are genuinely needed.

## Experiments

1. **Dispatch loop** — Issues auto-assigned to Copilot based on labels
2. **Spec / planning** — Copilot proposes plan before coding
3. **Verify** — Independent review via separate workflow
4. **Multi-agent chaining** — Sequential agents on one issue
5. **Self-improving loop** — Analyze closed PRs, update AGENTS.md
